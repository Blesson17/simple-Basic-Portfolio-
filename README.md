# Basic Portfolio Website

A simple personal portfolio website built using HTML and CSS. The website contains two main sections: **Home** and **Contact**. It provides a basic introduction and a way for visitors to get in touch.

## Features
- **Home:** Introduces the portfolio owner.
- **Contact:** Provides contact information for visitors.

## Technologies Used
- HTML5
- CSS3

## Purpose
This project was created to practice basic HTML and CSS concepts, page structure, styling, and website navigation.

## Future Improvements
- Add an About Me section.
- Add a Projects section.
- Improve the design with responsive layouts.
- Add social media links.
